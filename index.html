      01Flagship B.Tech research prototype

      ASTRA agentic AI that guards the door to the blockchain

      Autonomous Security & Threat Response for blockchain networks. A LangGraph multi-agent system vets every node before it joins the chain. The agents recommend; a human administrator makes the final, binding decision.

      With Amisha Rawat · supervised by Prof. Rahul Johari (USAR, GGSIPU)

      Code Demo video

      How it works

      • A Monitor agent gathers chain and P2P telemetry on a node asking to join, then dispatches four specialists: Sybil, Wallet, Finney and Eclipse.
      • Their scores combine into a Trust Factor, checked against a threshold before anything is decided.
      • Admitted nodes stay on probation for their first 10 transactions, with the Trust Factor recomputed after each one.
      • All four pre-admission attacks run live on a local Ethereum chain (Ganache).

      After admission, agents watch for

      • 51% attacks
      • Double-spending
      • Selfish mining
      • Block withholding
      • Python
      • LangGraph
      • Ganache (Ethereum)
      • NetworkX
      • Streamlit
      • pytest
