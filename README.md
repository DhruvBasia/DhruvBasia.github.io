# dhruvbasia.github.io

Portfolio of **Dhruv Basia**, B.Tech AI & Data Science (GGSIPU '27), New Delhi.

Live: https://dhruvbasia.github.io/

A single static page: hand-written HTML, CSS and vanilla JavaScript, no framework or build step.
The GitHub section reads a stored snapshot in `data/` made by `scripts/fetch-github.mjs`:

```bash
GITHUB_TOKEN=$(gh auth token) node scripts/fetch-github.mjs DhruvBasia
```
